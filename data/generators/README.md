# Data generators

Deterministic, template-based generators for VoltCart's knowledge base: manuals, return
policies, store policies, FAQs, internal playbooks and a marketplace listing. Run
`python scripts/generate_data.py`. Output goes to `data/generated/`, which git ignores.

See [docs/data.md](../../docs/data.md) for every document family, the facts table and the
failure each family triggers.
